# Tattoo Telegram Bot (Java)

Готовый Telegram-бот для тату-мастера:
- Java + Maven
- SQLite
- Dockerfile
- Inline-кнопки (по 1 в строке)
- Проверка подписки на канал
- Админ-панель
- Баланс пользователя и учет токенов
- Интеграция с `kie.ai` (`google/nano-banana`)

## Функции

### Пользовательское меню
1. `🖼️ Трансферный рисунок` — принимает фото и делает контурный трансфер.
2. `🎨 Эскиз` — принимает фото и делает тату-эскиз.
3. `🧠 Свободная генерация` — фото+промпт, фото затем промпт, либо только промпт.
4. `🛠️ Админ-панель` — видно только админам.

### Подписка на канал (обязательная)
- Пока пользователь не подписан, бот показывает:
  - кнопку `📢 Подписаться на канал`
  - кнопку `✅ Я подписался`
- При нажатии `Я подписался` бот проверяет `getChatMember`.
- Если пользователь отпишется позже, бот снова блокирует доступ к функциям.

### Админ-панель
- `👥 Список пользователей`
- `➕ Добавить админа` (по ID или `@username`, если пользователь уже есть в базе)
- `💰 Выдать баланс пользователю`
- `🏦 Учет баланса KIE` (текущий баланс по API)

## Переменные окружения
Скопируйте `.env.example` и задайте значения:

- `TELEGRAM_BOT_TOKEN`
- `KIE_API_KEY`
- `REQUIRED_CHANNEL_ID`
- `REQUIRED_CHANNEL_URL` (опционально, fallback если авто-генерация ссылки недоступна)

Опционально:
- `INITIAL_ADMIN_ID`
- `DEFAULT_DAILY_LIMIT`
- `DB_PATH`
- `KIE_*_ENDPOINT`

## Локальный запуск

```bash
mvn -DskipTests package
java -jar target/tattoo-bot.jar
```

## Запуск в Docker

```bash
docker build -t tattoo-bot .
docker run --env-file .env -v $(pwd)/data:/app/data tattoo-bot
```

## Как работает интеграция KIE

1. Используется только одна модель: `google/nano-banana`.
2. Максимальное ожидание результата от ИИ: 120 секунд.
3. Если за 120 секунд ответ не готов, пользователь получает сообщение: `Попробуйте снова`.
4. Каждая генерация списывает 4 токена у пользователя (дневной/бонусный баланс).

## Балансы

- Активному подписчику ежедневно доступно 40 токенов (10 генераций).
- В `/start` бот показывает текущий баланс пользователя.
- Админ может вручную начислять токены пользователям.
- В админке есть экран учета KIE:
  - кредитный баланс KIE по API (`GET /api/v1/chat/credit`).
