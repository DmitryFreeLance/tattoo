# Tattoo Telegram Bot (Java)

Telegram-бот для тату-студии:
- Java + Maven
- SQLite
- Dockerfile
- Inline-кнопки (по 1 в строке)
- Проверка подписки на канал
- Ежедневный лимит: `10 генераций в день` (МСК)
- Покупка только разовых пакетов генераций (через модерацию админом)
- Интеграция с `kie.ai`:
  - основная модель: `gpt-image-2` / `gpt-image-2-image-to-image`
  - fallback: `google/nano-banana`

## Логика доступа
1. Пользователь открывает бота.
2. Бот проверяет подписку на канал.
3. Если пользователь подписан, открывается меню.
4. Если пользователь отписался, бот снова блокирует использование до повторной подписки.
5. Кнопка подписки ведет на фиксированную ссылку: `https://t.me/fanpayonlinebot?startapp=chan_0c67e3e8-5354-4d7a-9527-9859be0301cf`.

## Лимиты и баланс
- Ежедневно начисляется `10 генераций` (`60 токенов`) по МСК.
- Списание за 1 генерацию: `6 токенов`.
- Разовые купленные пакеты начисляются как бонусные токены и не сгорают при ежедневном обновлении лимита.

## Главное меню
1. `🖼️ Трансферный рисунок`
2. `🧠 Свободная генерация`
3. `💳 Купить токены`
4. `🛠️ Админ-панель` (только админам)

## Покупка токенов
- Доступны пакеты:
  - `🎟️ 10 генераций — 69 ₽`
  - `🎟️ 20 генераций — 149 ₽`
- Оплата: `АкБарс`, карта `2200531114826215`.
- После оплаты пользователь нажимает `✅ Я оплатил`, затем указывает имя отправителя перевода.
- Админ получает заявку и подтверждает/отклоняет.

## Админ-панель
- `👥 Список пользователей`
- `➕ Добавить админа`
- `🎟️ Выдать доп. генерации`
- `🏦 Учет баланса KIE`
- Авто-уведомление, если баланс KIE ниже `100` токенов.

## KIE
- Основная модель: `gpt-image-2` (для работы с фото используется `gpt-image-2-image-to-image`).
- Если основная модель не отвечает за `120 секунд`, бот автоматически запускает fallback `google/nano-banana`.
- Если генерация завершилась ошибкой (в том числе после fallback), пользователю автоматически возвращаются списанные токены.

## Переменные окружения
Обязательные:
- `TELEGRAM_BOT_TOKEN`
- `KIE_API_KEY`
- `REQUIRED_CHANNEL_ID`

Опциональные:
- `TELEGRAM_BOT_USERNAME`
- `INITIAL_ADMIN_ID`
- `DB_PATH`
- `KIE_POLL_DELAY_MS`
- `KIE_CREATE_TASK_ENDPOINT`
- `KIE_RECORD_INFO_ENDPOINT`
- `KIE_FILE_UPLOAD_ENDPOINT`

## Локальный запуск

```bash
mvn -DskipTests package
java -jar target/tattoo-bot.jar
```

## Docker запуск

```bash
docker build -t tattoo-bot .
docker run --env-file .env -v $(pwd)/data:/app/data tattoo-bot
```
