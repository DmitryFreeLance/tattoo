# Tattoo Telegram Bot (Java)

Готовый Telegram-бот для тату-мастера:
- Java + Maven
- SQLite
- Dockerfile
- Inline-кнопки (по 1 в строке)
- Проверка подписки на канал
- Админ-панель
- Лимиты генераций в день (по Москве)
- Интеграция с `kie.ai` (Gemini 3 Flash + fallback на GPT Image 2)

## Функции

### Пользовательское меню
1. `🖼️ Трансферный рисунок` — принимает фото и делает контурный трансфер.
2. `🎨 Эскиз` — принимает фото и делает тату-эскиз.
3. `🧠 Свободная генерация` — фото+промпт, фото затем промпт, либо только промпт.
4. `🛠️ Админ-панель` — видно только админам.

### Подписка на канал (обязательная)
- Пока пользователь не подписан, бот показывает:
  - кнопку `📢 Подписаться на канал`
  - кнопку `✅ Я подписался`
- При нажатии `Я подписался` бот проверяет `getChatMember`.
- Если пользователь отпишется позже, бот снова блокирует доступ к функциям.

### Админ-панель
- `👥 Список пользователей`
- `➕ Добавить админа` (по ID или `@username`, если пользователь уже есть в базе)
- `📊 Лимит генераций в день (МСК)`

## Переменные окружения
Скопируйте `.env.example` и задайте значения:

- `TELEGRAM_BOT_TOKEN`
- `KIE_API_KEY`
- `REQUIRED_CHANNEL_ID`
- `REQUIRED_CHANNEL_URL` (опционально, fallback если авто-генерация ссылки недоступна)

Опционально:
- `INITIAL_ADMIN_ID`
- `DEFAULT_DAILY_LIMIT`
- `DB_PATH`
- `KIE_*_ENDPOINT`

## Локальный запуск

```bash
mvn -DskipTests package
java -jar target/tattoo-bot.jar
```

## Запуск в Docker

```bash
docker build -t tattoo-bot .
docker run --env-file .env -v $(pwd)/data:/app/data tattoo-bot
```

## Как работает интеграция KIE

1. Сначала запрос идет в `Gemini 3 Flash` (`/gemini-3-flash/v1/chat/completions`).
2. Если есть ошибка или не пришел валидный image-результат, бот автоматически переключается на:
   - `gpt-image-2-image-to-image` (если есть фото)
   - `gpt-image-2-text-to-image` (если только промпт)

## Важно про Gemini 3 Flash
По документации KIE для `Gemini 3 Flash (openai)` endpoint — это чат/completions-интерфейс (текстовый ответ, мультимодальный ввод).
На практике для надежной выдачи картинки в этом боте включен fallback на GPT Image 2.
