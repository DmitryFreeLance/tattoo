# Tattoo Telegram Bot (Java)

Готовый Telegram-бот для тату-студии:
- Java + Maven
- SQLite
- Dockerfile
- Inline-кнопки (по 1 в строке)
- Проверка подписки на канал
- Платная подписка (неделя/месяц) + проверка оплаты админом
- Админ-панель и управление генерациями
- Интеграция с `kie.ai` (`google/nano-banana`)

## Функции

### Пользовательский сценарий
1. Пользователь подписывается на канал.
2. После подписки бот показывает paywall с тарифами:
   - `🗓️ Недельная подписка — 199 ₽`
   - `🗓️ Месячная подписка — 699 ₽`
3. Пользователь переводит оплату на карту и нажимает `✅ Я оплатил`.
4. Админ получает заявку и подтверждает/отклоняет.
5. После подтверждения у пользователя активируется доступ.

### Главное меню
1. `🖼️ Трансферный рисунок`
2. `🧠 Свободная генерация`
3. `💳 Купить / продлить`
4. `🛠️ Админ-панель` (только админам)

### Подписка и лимиты
- Активная подписка дает `10 генераций в день` (обновление по МСК).
- Если сегодня использовано, например, `8/10`, то на следующий день снова будет `10/10`.
- Дополнительные (разовые) генерации не сгорают при ежедневном обновлении.

### Покупки в боте
- Продление подписки (неделя/месяц).
- Увеличение лимита в рамках активной подписки:
  - Для недельной: `+5/день (149 ₽)`, `+10/день (300 ₽)`.
  - Для месячной: `+5/день (640 ₽)`, `+10/день (1290 ₽)`.
- Разовые пакеты:
  - `10 генераций — 39 ₽`
  - `20 генераций — 99 ₽`

### Админ-панель
- `👥 Список пользователей`
- `➕ Добавить админа`
- `🎟️ Выдать доп. генерации`
- `🏦 Учет баланса KIE`
- Авто-уведомление админам, если баланс KIE стал меньше `100` токенов.

## Оплата
- Банк: `Т-Банк`
- Карта: `2200531114826215`
- После нажатия `Я оплатил` создается заявка на проверку.

## KIE
- Модель: только `google/nano-banana`.
- Максимальное ожидание генерации: `120 секунд`.
- В промпт автоматически добавляется усиление контраста/черного для более читаемой тату-графики.

## Переменные окружения
Обязательные:
- `TELEGRAM_BOT_TOKEN`
- `KIE_API_KEY`
- `REQUIRED_CHANNEL_ID`

Опциональные:
- `TELEGRAM_BOT_USERNAME`
- `REQUIRED_CHANNEL_URL`
- `INITIAL_ADMIN_ID`
- `DB_PATH`
- `KIE_POLL_DELAY_MS`
- `KIE_CREATE_TASK_ENDPOINT`
- `KIE_RECORD_INFO_ENDPOINT`
- `KIE_FILE_UPLOAD_ENDPOINT`

## Локальный запуск

```bash
mvn -DskipTests package
java -jar target/tattoo-bot.jar
```

## Запуск в Docker

```bash
docker build -t tattoo-bot .
docker run --env-file .env -v $(pwd)/data:/app/data tattoo-bot
```
